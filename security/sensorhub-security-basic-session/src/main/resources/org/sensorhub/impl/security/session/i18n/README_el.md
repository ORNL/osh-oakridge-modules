# Βασικός έλεγχος ταυτότητας συνεδρίας

Η μονάδα **Βασικός έλεγχος ταυτότητας συνεδρίας** επαληθεύει τα αιτήματα του προγράμματος περιήγησης και του API χρησιμοποιώντας ένα αδιαφανές cookie συνεδρίας στον διακομιστή μετά τον έλεγχο των διαπιστευτηρίων του χρήστη.

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Αδιαφανές cookie συνεδρίας (Opaque Session Cookie)** | Ένα τυχαίο αναγνωριστικό που αποθηκεύεται στο πρόγραμμα περιήγησης μετά τη σύνδεση. Αντί να αποστέλλεται ο κωδικός πρόσβασης σε κάθε αίτημα, αποστέλλεται αυτό το αναγνωριστικό και το OSCAR ελέγχει την ενεργή συνεδρία στον διακομιστή. |
| **Όριο αδράνειας έναντι Απόλυτου ορίου** | Το **Όριο αδράνειας** αποσυνδέει τον χρήστη μετά από περίοδο ανενεργότητας· το **Απόλυτο όριο** απαιτεί εκ νέου σύνδεση μετά από μέγιστο συνολικό χρόνο ακόμη και αν ο χρήστης είναι ενεργός. |
| **Πολιτική SameSite** | Κανόνας προγράμματος περιήγησης για την αποστολή cookie μεταξύ τοποθεσιών. Η τιμή `Strict` περιορίζει το cookie στον τοπικό κόμβο, ενώ η τιμή `None` επιτρέπει ομοσπονδιακές συνδέσεις πολλαπλών κόμβων μέσω HTTPS. |

## Αναφορά ρυθμίσεων

- **Όνομα cookie συνεδρίας (`Session cookie name`)**: Το όνομα του cookie που αποθηκεύει το αναγνωριστικό συνεδρίας.
- **Χρονικό όριο αδράνειας (δευτερόλεπτα) (`Idle timeout`)**: Δευτερόλεπτα αδράνειας πριν από τη λήξη της συνεδρίας.
- **Απόλυτο χρονικό όριο (δευτερόλεπτα) (`Absolute timeout`)**: Μέγιστη συνολική διάρκεια ζωής μιας συνεδρίας.
- **Ασφαλές cookie (`Secure cookie`)**: Αποστολή του cookie μόνο μέσω κρυπτογραφημένων συνδέσεων HTTPS. Διατηρήστε το ενεργό σε περιβάλλον παραγωγής.
- **Πολιτική SameSite (`SameSite policy`)**: Πολιτική αποστολής cookie (`Strict`, `Lax` ή `None`).
- **Προεπιλεγμένη διαδρομή ανακατεύθυνσης (`Default redirect path`)**: Τοπική διαδρομή μετά τη σύνδεση όταν δεν υπάρχει αποθηκευμένος προορισμός.
