# Διεργασία διέλευσης RS350

Η **Διεργασία διέλευσης RS350** παρακολουθεί μια λωρίδα εξοπλισμένη με φασματοσκοπικό ανιχνευτή ακτινοβολίας **RS-350**, ομαδοποιεί κάθε παράθυρο διέλευσης ή φασματοσκοπικού συναγερμού σε συμβάν **Διέλευσης (Occupancy)** του OSCAR (συμπεριλαμβανομένων φασμάτων προσκηνίου/υποβάθρου και ανάλυσης ισοτόπων) και συντονίζει την καταγραφή βίντεο/καρέ στη γονική λωρίδα.

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Φασματοσκοπικός ανιχνευτής RS-350** | Ανιχνευτής γάμμα/νετρονίων που παράγει πλήρη ενεργειακά φάσματα (μορφή `N42`) εκτός από τους ρυθμούς καταμέτρησης, επιτρέποντας την αυτόματη ταυτοποίηση ισοτόπων (`WebID`). |
| **Διέλευση (`Occupancy`)** | Μία διέλευση ή παράθυρο μέτρησης που οριοθετείται από την έναρξη και τη λήξη διέλευσης στη λωρίδα. |

## Αναφορά ρυθμίσεων

- **Σειριακός αριθμός (`Serial Number`)**: Μοναδικό αναγνωριστικό για αυτήν τη διεργασία διέλευσης RS-350.
- **Γονικό σύστημα (`Parent System (Containing RPM)`)**: Το UID του γονικού συστήματος λωρίδας που περιέχει τον οδηγό RS-350 και τις κάμερες. Αφήστε το κενό για αυτόματη σύνδεση με τη γονική λωρίδα.
