# Διεργασία διέλευσης Kromek D5

Η **Διεργασία διέλευσης Kromek D5** παρακολουθεί έναν φορητό ανιχνευτή ή γονικό σύστημα εξοπλισμένο με φορητό ανιχνευτή ακτινοβολίας **Kromek D5**, ομαδοποιεί τις ενδείξεις συναγερμού δόσης, γάμμα και νετρονίων 1 Hz σε διακριτά επεισόδια συναγερμού και δημοσιεύει κάθε επεισόδιο ως συμβάν **Διέλευσης (Occupancy)** του OSCAR (με μέγιστες καταμετρήσεις, κατηγορία συναγερμού και συντεταγμένες GPS).

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Φορητός ανιχνευτής Kromek D5** | Φορητός φασματοσκοπικός ανιχνευτής γάμμα/νετρονίων μέσω TCP ή USB/σειριακής σύνδεσης που αναφέρει ενεργούς συναγερμούς, φάσματα 4.096 καναλιών και θέση GPS. |
| **Επεισόδιο συναγερμού (`Occupancy`)** | Παράθυρο ραδιολογικού συναγερμού που ξεκινά με την ενεργοποίηση συναγερμού D5 και κλείνει όταν οι ενδείξεις παραμείνουν ανενεργές για 3 δευτερόλεπτα. |

## Αναφορά ρυθμίσεων

- **Σειριακός αριθμός (`Serial Number`)**: Μοναδικό αναγνωριστικό για αυτήν τη διεργασία διέλευσης Kromek D5.
- **Γονικό σύστημα (`Parent System (Containing RPM)`)**: Το UID του γονικού συστήματος που περιέχει τον οδηγό Kromek D5. Αφήστε το κενό για αυτόματη σύνδεση με το γονικό σύστημα.
