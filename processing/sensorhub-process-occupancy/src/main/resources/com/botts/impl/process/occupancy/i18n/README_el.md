# Διεργασία δεδομένων διέλευσης (Occupancy)

Η **Διεργασία δεδομένων διέλευσης** παρακολουθεί τη ροή της πύλης ανίχνευσης ακτινοβολίας (RPM) μιας λωρίδας, ομαδοποιεί κάθε διέλευση οχήματος ή πεζού σε μια δομημένη εγγραφή **Διέλευσης (Occupancy)** (με ώρα έναρξης, ώρα λήξης, ενδείξεις συναγερμού γάμμα/νετρονίων, μέγιστες μετρήσεις και σχετικά καρέ/βίντεο κάμερας) και ενεργοποιεί την αποθήκευση πολυμέσων όταν προκύπτει συναγερμός.

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Διέλευση (`Occupancy`)** | Μία μεμονωμένη διέλευση οχήματος, εμπορευματοκιβωτίου ή ατόμου από λωρίδα ανίχνευσης μεταξύ έναρξης (`GS`) και λήξης (`GX`) διέλευσης. |
| **UUID συμβάντος (`Event UUID`)** | Παγκοσμίως μοναδικό αναγνωριστικό που αποδίδεται σε κάθε συμβάν διέλευσης για αναζήτηση, αξιολόγηση και αναφορά. |
| **UID γονικού συστήματος (`Parent System UID`)** | Το μοναδικό αναγνωριστικό (`urn:osh:system:lane:...`) του συστήματος λωρίδας που περιέχει το RPM και τις κάμερες. |

## Αναφορά ρυθμίσεων

- **Σειριακός αριθμός (`Serial Number`)**: Μοναδικό αναγνωριστικό για αυτήν τη διεργασία διέλευσης (συνήθως συμπίπτει με το αναγνωριστικό της λωρίδας).
- **Γονικό σύστημα (`Parent System (Containing RPM)`)**: Το UID του συστήματος λωρίδας που περιέχει το RPM. Αν μείνει κενό, χρησιμοποιείται αυτόματα το γονικό σύστημα λωρίδας.
