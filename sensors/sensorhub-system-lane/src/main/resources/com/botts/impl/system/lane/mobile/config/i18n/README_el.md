# Σύστημα φορητού ανιχνευτή

Αναπτύσσει έναν φορητό ανιχνευτή ακτινοβολίας — **σακίδιο RS-350** ή φορητό ανιχνευτή **Kromek D5** — ως ανιχνεύσιμο σύστημα στο OSCAR. Χρησιμοποιήστε αυτόν τον τύπο μονάδας αντί για τα μεμονωμένα προγράμματα οδήγησης RS-350/D5 ή ένα σταθερό **Σύστημα λωρίδας** (το οποίο εμφανίζει ρυθμίσεις καμερών, WebRelay και OCR οχημάτων που δεν ισχύουν για φορητή μονάδα).

Ο ανιχνευτής εμφανίζεται στο OSCAR Viewer με ζωντανή παρακολούθηση GPS στον χάρτη, δείκτες συναγερμού σε πραγματικό χρόνο, φασματοσκοπική ταυτοποίηση ισοτόπων (`WebID` για RS-350) και αξιολόγηση επεισοδίων συναγερμού στον πίνακα συμβάντων.

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Σακίδιο RS-350** | Φορητός φασματοσκοπικός ανιχνευτής γάμμα/νετρονίων που μεταδίδει φάσματα `N42`, συναγερμούς και θέση GPS μέσω TCP. |
| **Φορητό Kromek D5** | Χειροκίνητος φασματοσκοπικός ανιχνευτής γάμμα/νετρονίων με δειγματοληψία 1 Hz μέσω TCP για ραδιομετρική κατάσταση, φάσματα 4.096 καναλιών και θέση GPS. |
| **Σύνδεση ανιχνευτή (`Detector Connection`)** | Ενιαία διεύθυνση host και θύρα TCP του φορητού ανιχνευτή, σε αυτόματο συγχρονισμό με το υποκείμενο πρόγραμμα οδήγησης. |

## Αναφορά ρυθμίσεων

- **Όνομα μονάδας (`Module Name`)**: Εμφανιζόμενο όνομα του φορητού ανιχνευτή (έως 12 χαρακτήρες).
- **Μοναδικό αναγνωριστικό (`Unique ID`)**: Μοναδικό επίθημα (π.χ. `backpack-01`), αντιστοιχισμένο στο `urn:osh:system:lane:<uniqueID>`.
- **Κλειδιά επιχειρησιακής προβολής (`Operational View Keys`)**: Προαιρετικές πεζές ετικέτες που καθορίζουν ποιοι χειριστές βλέπουν τη φορητή μονάδα.
- **Σύνδεση ανιχνευτή (`Detector Connection`)**: Επιλέξτε **Σακίδιο RS-350** ή **Kromek D5** και συμπληρώστε **Απομακρυσμένος κεντρικός υπολογιστής** και **Απομακρυσμένη θύρα**.
