# Σύστημα αισθητήρων λωρίδας

Το **Σύστημα αισθητήρων λωρίδας** δημιουργεί ένα γονικό σύστημα για μία πύλη ανίχνευσης ακτινοβολίας (RPM), τη διεργασία διέλευσης και έως τέσσερις κάμερες λωρίδας.

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Κλειδί επιχειρησιακής προβολής (`Operational View Key`)** | Προαιρετική ετικέτα (π.χ. `north-gate` ή `cargo-inbound`) που ομαδοποιεί τη λωρίδα σε έναν επώνυμο χώρο εργασίας χειριστή στο OSCAR Viewer. |
| **Λόγοι ενεργειακών μετρικών (`EML`)** | Προαιρετικός αλγόριθμος Rapiscan που συγκρίνει μετρήσεις γάμμα χαμηλής, μεσαίας και υψηλής ενέργειας για να διακρίνει τη φυσική ακτινοβολία φορτίων (**NORM**, αυτόματη αξιολόγηση ως `Code 9999: EML Non-Threat`) από πηγές απειλής. |
| **Εύρος διευθύνσεων Modbus** | Εύρος καταχωρητών (`Από` και `Έως`) που χρησιμοποιείται από τους ελεγκτές Aspect μέσω TCP/IP. |

## Γενικές ρυθμίσεις

- **Όνομα μονάδας** και **Μοναδικό ID**: Δώστε στη λωρίδα μοναδικό όνομα και μοναδικό αναγνωριστικό.
- **Κλειδί επιχειρησιακής προβολής**: Προαιρετικό κλειδί για την αντιστοίχιση της λωρίδας σε Επιχειρησιακή Προβολή στην Υπηρεσία OSCAR.
- **Τοποθεσία**: Εισαγάγετε το σταθερό γεωγραφικό πλάτος και μήκος της λωρίδας.
- **Διαγραφή δεδομένων κατά την αφαίρεση λωρίδας**: Ενεργοποιήστε το **μόνο** όταν η αφαίρεση της λωρίδας πρέπει να διαγράψει και τα αποθηκευμένα ιστορικά δεδομένα της.

## Επιλογές λωρίδας

- **Αρχική ρύθμιση RPM**:
  - Επιλέξτε **Rapiscan**, **Aspect** ή **RS-350** και εισαγάγετε τη διεύθυνση host και τη θύρα TCP.
  - Για **Aspect**, συμπληρώστε επίσης το εύρος διευθύνσεων Modbus.
  - Για **Rapiscan**, ρυθμίστε τις επιλογές **EML** εάν έχει μεταφορτωθεί πρόσθετο `.jar` EML στον κόμβο.
- **Αρχική ρύθμιση κάμερας**:
  - Προσθέστε έως **4** κάμερες **Sony**, **Axis** ή **Custom** ανά λωρίδα.
  - Για κάμερες **Axis**, επιλέξτε τον κωδικοποιητή ροής (`H.264`). Για κάμερες **Custom**, εισαγάγετε τη διαδρομή μετά το host και τη θύρα.
- Πατήστε **Εφαρμογή** και **Αποθήκευση** στην επάνω γραμμή εργαλείων για τη δημιουργία και εκκίνηση των θυγατρικών μονάδων.
