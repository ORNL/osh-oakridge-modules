# Σύστημα αισθητήρων λωρίδας

Το **Σύστημα αισθητήρων λωρίδας** δημιουργεί ένα γονικό σύστημα για μία πύλη ανίχνευσης ακτινοβολίας (RPM), τη διεργασία διέλευσης και έως τέσσερις κάμερες λωρίδας.

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Κλειδί επιχειρησιακής προβολής (`Operational View Key`)** | Προαιρετική ετικέτα (π.χ. `north-gate` ή `cargo-inbound`) που ομαδοποιεί τη λωρίδα σε έναν επώνυμο χώρο εργασίας χειριστή στο OSCAR Viewer. |
| **Ενισχυμένη μηχανική μάθηση (`EML`, Enhanced Machine Learning)** | Προαιρετικός αλγόριθμος Rapiscan που συγκρίνει μετρήσεις γάμμα χαμηλής, μεσαίας και υψηλής ενέργειας για να διακρίνει τη φυσική ακτινοβολία φορτίων (**NORM**, αυτόματη αξιολόγηση ως `Code 9999: EML Non-Threat`) από πηγές απειλής. |
| **OCR οχημάτων (`ocrConfig`)** | Προαιρετική ασύγχρονη οπτική αναγνώριση ανά λωρίδα (`Ενεργοποίηση OCR οχημάτων = false` από προεπιλογή) που διαβάζει αριθμούς εμπορευματοκιβωτίων ISO 6346 (με επαλήθευση ψηφίου ελέγχου) και πινακίδες κυκλοφορίας ανάλογα με τους διαθέσιμους πόρους CPU/μνήμης, δημοσιεύοντας προτάσεις `vehicleOcr` (`PARQUET_PRIMARY`), αποκόμματα ανά ημερομηνία (`files/ocr/crops/<YYYY-MM-DD>/`, ευθυγραμμισμένα με το `frame-03.jpg` και `ocrCropRetentionDays = 365`) και αυτόματη συμπλήρωση του **ID οχήματος**. Όταν η επιλογή `Μόνο συναγερμοί` απενεργοποιηθεί, οι καταγραφές χωρίς συναγερμό σαρώνονται προσωρινά και διαγράφονται αμέσως μετά το OCR διατηρώντας το `occupancy.videoPaths` κενό (`[]`). |
| **Φώτα και ήχος RPM (`webRelayConfig`)** | Προαιρετικός δικτυακός έλεγχος ρελέ ανά λωρίδα (`Ενεργοποίηση ελέγχου WebRelay = false` από προεπιλογή) για μονάδες ControlByWeb WebRelay-Quad (`X-WR-4R3-E` / `X-410`) μέσω HTTP/XML (`stateFull.xml` / `state.xml`). Υποστηρίζει **Αυτόματη λειτουργία (`AUTO`)** (όπλιση `R1=1, R2=1` κατά τη διέλευση, καταστολή φώτων/σειρήνας σε `Code 9999: EML Non-Threat` και προαιρετικά σε `Code 9998: Extended Occupancy Gamma Alarm`, και παλμό `R3` κόκκινου φωτός γάμμα + σειρήνας ή/και `R4` μπλε φωτός νετρονίων σε πραγματικούς συναγερμούς), **Άμεση διέλευση (`PASS_THROUGH`)**, **Σίγαση (`MUTED`)** και χειροκίνητο έλεγχο διαχειριστή σε κύρια και προαιρετική βοηθητική μονάδα. |
| **Εύρος διευθύνσεων Modbus** | Εύρος καταχωρητών (`Από` και `Έως`) που χρησιμοποιείται από τους ελεγκτές Aspect μέσω TCP/IP. |

## Γενικές ρυθμίσεις

- **Όνομα μονάδας** και **Μοναδικό ID**: Δώστε στη λωρίδα μοναδικό όνομα και μοναδικό αναγνωριστικό.
- **Κλειδί επιχειρησιακής προβολής**: Προαιρετικό κλειδί για την αντιστοίχιση της λωρίδας σε Επιχειρησιακή Προβολή στην Υπηρεσία OSCAR.
- **OCR οχημάτων**: Προαιρετικές ρυθμίσεις ανά λωρίδα (`Ενεργοποίηση OCR οχημάτων`, `Μόνο συναγερμοί`, `Κατάλογος μοντέλων`, `Ανάγνωση αριθμών εμπορευματοκιβωτίων`, `Ανάγνωση πινακίδων κυκλοφορίας`, `UID καμερών`, `Καρέ ανά κλιπ`, `Ελάχιστη βεβαιότητα εμπορευματοκιβωτίου`, `Ελάχιστη βεβαιότητα πινακίδας`, `Παράβλεψη άνω ζώνης`, `Παράβλεψη κάτω ζώνης`). Απενεργοποιημένο από προεπιλογή χωρίς καμία επιβάρυνση όταν είναι ανενεργό.
- **Φώτα και ήχος RPM (WebRelay-Quad)**: Προαιρετικές ρυθμίσεις ανά λωρίδα (`Ενεργοποίηση ελέγχου WebRelay`, `Λειτουργία ελέγχου`, `Καταστολή συναγερμού γάμμα παρατεταμένης διέλευσης (Κωδικός 9998)`, `Κύριο Host / IP`, `Θύρα HTTP`, προαιρετικό `Όνομα χρήστη` / `Κωδικός πρόσβασης`, διάρκειες παλμών γάμμα/νετρονίων και προαιρετική βοηθητική μονάδα ξηρών επαφών) με κουμπιά άμεσου ελέγχου για διαχειριστές.
- **Τοποθεσία**: Εισαγάγετε το σταθερό γεωγραφικό πλάτος και μήκος της λωρίδας.
- **Διαγραφή δεδομένων κατά την αφαίρεση λωρίδας**: Ενεργοποιήστε το **μόνο** όταν η αφαίρεση της λωρίδας πρέπει να διαγράψει και τα αποθηκευμένα ιστορικά δεδομένα της.

## Επιλογές λωρίδας

- **Αρχική ρύθμιση RPM**:
  - Επιλέξτε **Rapiscan**, **Aspect** ή **RS-350** και εισαγάγετε τη διεύθυνση host και τη θύρα TCP.
  - Για **Aspect**, συμπληρώστε επίσης το εύρος διευθύνσεων Modbus.
  - Για **Rapiscan**, ρυθμίστε τις επιλογές **EML** εάν έχει μεταφορτωθεί πρόσθετο `.jar` EML στον κόμβο.
- **Αρχική ρύθμιση κάμερας**:
  - Προσθέστε έως **4** κάμερες **Sony**, **Axis** ή **Custom** ανά λωρίδα.
  - Για κάμερες **Axis**, επιλέξτε τον κωδικοποιητή ροής (`H.264`). Για κάμερες **Custom**, εισαγάγετε τη διαδρομή μετά το host και τη θύρα.
- Πατήστε **Εφαρμογή** και **Αποθήκευση** στην επάνω γραμμή εργαλείων για τη δημιουργία και εκκίνηση των θυγατρικών μονάδων.
