# Υπηρεσία αποθήκευσης κάδων (Bucket Storage)

Η **Υπηρεσία αποθήκευσης κάδων** παρέχει τοπική αποθήκευση αντικειμένων στο σύστημα αρχείων για τα αρχεία του OSCAR, συμπεριλαμβανομένων των διαγραμμάτων εγκατάστασης, των παραγόμενων αναφορών (`reports/`), των συνημμένων αξιολόγησης, των προσθέτων EML και των διατηρούμενων πολυμέσων συμβάντων (`videos/`).

## Επεξήγηση όρων σε απλή γλώσσα

| Όρος | Σημασία |
| --- | --- |
| **Κάδος (Bucket)** | Ένας επώνυμος λογικός φάκελος που διαχειρίζεται το OSCAR (όπως `reports`, `videos`, `site-diagram` ή `eml`) για την αποθήκευση και ασφαλή διάθεση αρχείων μέσω HTTPS. |
| **CORS (Κοινή χρήση πόρων διαφορετικής προέλευσης)** | Τυπικές κεφαλίδες ασφαλείας προγράμματος περιήγησης που επιτρέπουν στο OSCAR Viewer να φορτώνει εικόνες, αναφορές και πολυμέσα από τον διακομιστή SensorHub. |

## Αναφορά ρυθμίσεων

- **Ριζικός κατάλογος αποθήκευσης αρχείων (`File Store Root Directory`)**: Ο τοπικός φάκελος δίσκου όπου αποθηκεύονται όλοι οι κάδοι και τα αρχεία.
- **Αρχικοί κάδοι (`Initial Buckets`)**: Λίστα ονομάτων κάδων που δημιουργούνται αυτόματα κατά την εκκίνηση της υπηρεσίας.
- **Μέγιστο μέγεθος αρχείου (MB) (`Max File Size (MB)`)**: Μέγιστο επιτρεπόμενο μέγεθος (σε megabyte) ανά μεταφορτωμένο αρχείο.
- **Ενεργοποίηση CORS (`Enable CORS`)**: Προσθέτει κεφαλίδες CORS ώστε το OSCAR Viewer να μπορεί να ανακτά και να μεταφορτώνει αρχεία.
- **Ασφάλεια (`Security`)**: Κανόνες ελέγχου πρόσβασης που καθορίζουν ποιοι πιστοποιημένοι χρήστες μπορούν να διαβάζουν ή να μεταφορτώνουν αρχεία.
