# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting on [`ORNL/oscar`](https://github.com/ORNL/oscar/security) or directly to the repository maintainers (`@tyronechrisharris`). Never include deployment secrets, private TLS keys, or internal host addresses in reports or test fixtures.
